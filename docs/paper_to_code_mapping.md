# Paper-to-Code Mapping Table (CDA)

This document maps every conceptual and mathematical component of **CDA** (*Efficient Industrial Anomaly Detection via Cross-Scale Distillation with Enhanced Feature Compression*, Pattern Recognition 2026) to its exact implementation in the official author repository (`https://github.com/WHUer-cloud/CDA`) and our modular research repository (`src/anomaly_detection/`).

---

## 1. Architectural Module Mapping

| Paper Component | Mathematical / Conceptual Description | Official Code File & Symbol | Input Tensor Shape ($B, \dots$) | Output Tensor Shape ($B, \dots$) | Parameter Count | Agreement & Discrepancies |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Teacher Encoder** | Frozen pretrained `Wide_ResNet50_2` extracting multi-scale features from `layer1`, `layer2`, `layer3` | `model.py`: `Encoder` | `(B, 3, 256, 256)` | `e1: (B, 256, 64, 64)`<br/>`e2: (B, 512, 32, 32)`<br/>`e3: (B, 1024, 16, 16)` | `24,862,528` (frozen) | **Exact agreement.** Uses `Wide_ResNet50_2_Weights.DEFAULT` in `.eval()` mode. |
| **Global-local Compression Module (GCM)** | Bottleneck module combining CLE (local strided CNNs) and SGA (global multi-scale attention), followed by residual stride-2 downsampling | `model.py`: `GCM` | `e1: (B, 256, 64, 64)`<br/>`e2: (B, 512, 32, 32)`<br/>`e3: (B, 1024, 16, 16)` | `f: (B, 2048, 8, 8)` | `19,704,579` | **Exact agreement.** Comment in `model.py` line 121 labels section `# ---------- OCBE + Decoder ----------`, confirming heritage from RD4AD's OCBE. |
| **Channel-oriented Local Extraction (CLE)** | Stride-4 ConvBlock on $e_1$, stride-2 ConvBlock on $e_2$, concatenated with $e_3$ and fused via $1\times1$ conv | `model.py`: `GCM.local1`, `GCM.local2`, `GCM.merge`, `ConvBlock` | `e1: (B, 256, 64, 64)`<br/>`e2: (B, 512, 32, 32)`<br/>`e3: (B, 1024, 16, 16)` | `l1: (B, 1024, 16, 16)`<br/>`l2: (B, 1024, 16, 16)`<br/>`l: (B, 1024, 16, 16)` | `local1`: `2.04M`<br/>`local2`: `3.68M`<br/>`merge`: `3.15M`<br/>(Total: `8.87M`) | **Exact agreement.** `ConvBlock` uses `1x1 -> 3x3 -> 1x1` with `BatchNorm2d` + `GELU` and a `1x1` residual shortcut. |
| **Spatial-guided Global Attention (SGA)** | Resizes $e_1, e_2$ to $16\times16$, compresses channels to $1$ via $1\times1$ convs, runs 6-pair RoPE multi-head attention over $L=256$ spatial positions, and fuses via `DoubleConv` | `Transformer.py`: `Fusion`, `SelfAttention`, `DoubleConv` | `x1: (B, 256, 64, 64)`<br/>`x2: (B, 512, 32, 32)`<br/>`x3: (B, 1024, 16, 16)` | `g: (B, 1024, 16, 16)` | `1,384,451` (`transformer`: `67.3K`, `DoubleConv`: `1.32M`) | **Minor implementation quirk:** In `SelfAttention.forward` (line 147), attention scaling uses `K.shape[2]` ($L=256$) instead of head dim $d_h=32$, and reshapes output assuming fixed $16 \times 16$ grid (`view(b, 256, 16, 16)`). |
| **GCM Bottleneck Downsampler** | Fuses global ($g$) and local ($l$) features by element-wise addition and downsamples $16\times16 \to 8\times8$ while expanding channels $1024 \to 2048$ | `model.py`: `GCM.res` (`ConvBlock(1024, 3, [512, 1024, 2048], 2)`) | `g + l: (B, 1024, 16, 16)` | `f: (B, 2048, 8, 8)` | `9,454,080` (`9.45M`) | **Exact agreement.** Accounts for 48% of `GCM`'s parameters. |
| **Lightweight Student Decoder** | 3-stage hierarchical upsampling decoder (`l3`, `l2`, `l1`) mapping bottleneck $f$ back to scales $16\times16, 32\times32, 64\times64$ | `model.py`: `Decoder`, `PatchExpand2D`, `GSULayer` | `f: (B, 2048, 8, 8)` | `s3: (B, 1024, 16, 16)`<br/>`s2: (B, 512, 32, 32)`<br/>`s1: (B, 256, 64, 64)` | `6,959,616` (`l3: 5.29M`, `l2: 1.33M`, `l1: 0.34M`) | **Exact agreement.** `Decoder.forward` returns 9 tensors `(s1, s2, s3, s2, s3, s1, s3, s1, s2)` for same-scale and cross-scale paths. |
| **Gated-depth Sequence Unit (GSU)** | Pre-RMSNorm residual block with dual linear projection, causal depthwise `Conv1d(k=4)`, `DepthwiseMLP` (`GroupedLinear` + `SiLU`), RMSNorm, SiLU gate, and output linear layer | `model.py`: `GSULayer`, `GSU`, `DepthwiseMLP`, `GroupedLinear`, `RMSNorm` | `(B, L, d)` where $(L, d) \in \{(256, 1024), (1024, 512), (4096, 256)\}$ | `(B, L, d)` | Included in `Decoder` (`6.96M` total) | **Exact agreement.** Git commit `1004444` shows the section comment was renamed from `# ---------- Mamba ----------` to `# ---------- GSU ----------`. |
| **Cross-Scale Distillation Alignment** | Bilinearly resizes each student scale $s_j$ to the other two scales $H_i \times W_i$ ($i \neq j$) and applies $3\times3$ conv channel alignment | `model.py`: `GCMAndDecoder.c11, c12, c21, c22, c31, c32` | `s1, s2, s3` | `l1m, l1n: (B, 256, 64, 64)`<br/>`l2m, l2n: (B, 512, 32, 32)`<br/>`l3m, l3n: (B, 1024, 16, 16)` | `16,518,656` (`16.52M`) | **Critical finding:** These 6 dense $3\times3$ convolutions account for **38.3%** of all trainable parameters (`16.52M` vs. `6.96M` for the GSU decoder). |

## 2. Training, Loss, Data, and Evaluation Mapping

| Paper / Pipeline Stage | Conceptual Role | Official Code File & Function | Our Repository Module | Discrepancies / Bugs Identified in Official Code |
| :--- | :--- | :--- | :--- | :--- |
| **Dataset Loading (Train & Test)** | Loads MVTec AD normal training images and test images + ground-truth masks resized to $256\times256$ | `dataloder.py`: `TrainDataset`, `TestDataset` | `src/anomaly_detection/data/mvtec.py` | 1. **Import Bug:** File is named `dataloder.py`, but `train.py` and `test.py` import `from data_loader import ...` (`ModuleNotFoundError`).<br/>2. **Hard-coded GT path:** `TestDataset` hard-codes `self.gt_root = "./datasets/mvtec/..."` ignoring `--data_path`.<br/>3. **OS Path Bug:** Uses `img_path.split("/")` and `[:3]`, which breaks on Windows backslashes `\` or non-3-digit filenames. |
| **Same-Scale & Cross-Scale Distillation Loss** | Computes weighted cosine distance between teacher $(e_1, e_2, e_3)$ and student $(s_1..s_3, l_{1m}..l_{3n})$ | `train.py` lines 42–46; `metric.py`: `cos_dist` | `src/anomaly_detection/losses/cda_loss.py` | **Weighting Asymmetry:** `train.py` writes `(0.4 * cos_dist(e1, l1n) + cos_dist(e1, l1m)).mean()`, whereas `metric.py` applies `0.4` to `(cos_dist(e1, l1n) + cos_dist(e1, l1m))`. |
| **Anomaly Map Generation & Smoothing** | Upsamples 3 same-scale and 3 cross-scale cosine distance maps to `img_size`, combines them, and applies Gaussian filter ($\sigma=4$) | `metric.py`: `anomaly_score` | `src/anomaly_detection/inference/anomaly_mapper.py` | Uses `scipy.ndimage.gaussian_filter(score[i], sigma=4)` on CPU numpy arrays. |
| **Metric Computation** | Computes Image-level AUROC (from max pixel score) and Pixel-level AUROC | `metric.py`: `compute_auroc` | `src/anomaly_detection/evaluation/metrics.py` | **Hard-coded Resolution Bug:** `compute_auroc` line 47 hard-codes `scores.reshape(-1, 256*256)`, which crashes if `img_size != 256`. Also lacks Image-AP, Pixel-AP, and AUPRO. |
| **Training Loop & Checkpoint Selection** | Trains `GCMAndDecoder` for 160 epochs with Adam (`lr=0.005, betas=(0.5, 0.999)`) | `train.py`: `train` | `src/anomaly_detection/training/trainer.py` | 1. **Directory Creation Bug:** `ck_dir.mkdir(exist_ok=True)` fails with `FileNotFoundError` because parent `checkpoints/WRes50` is not created with `parents=True`.<br/>2. **Test-Set Selection Leakage:** Evaluates on test set every 5 epochs and saves `best_img.pth` and `best_pix.pth` using test AUROC.<br/>3. **No Resume Support:** Official `train.py` only saves `dec.state_dict()` without optimizer state or epoch counter. |
