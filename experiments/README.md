# Experiment Registry and Research Logs

This directory stores lightweight, version-controlled experiment logs (`*.csv`, `*.json`, and signed markdown notes) summarizing verified runs on Kaggle GPU sessions.

> **Important Rule:** Do not commit `.pth` checkpoints, raw datasets, or bulk heatmap folders here. Only verified summary tables and run metadata belong in `experiments/`.

See [docs/experiment_matrix.md](../docs/experiment_matrix.md) for the complete experiment schedule (`R00`, `B0`, `A1`–`A3`, `B1`–`B3`, `C1`).
